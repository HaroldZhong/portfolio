Case study

BRAT AI

Conversational family therapy training and assessment application. Parents rehearse difficult conversations with a simulated teen in English or Spanish while a separate real-time evaluator assesses their technique.

Problem

Rehearsing a hard conversation only helps if the simulated teen stays believable, the feedback addresses the right techniques, and sensitive moments are handled safely, in English or Spanish.

My contribution

As Product and AI Engineering Lead, I lead Next.js/Node.js development and Azure deployment, and I translate parent-training requirements into the role-play, evaluation, safety and versioning design.

Technical & design decisions

  1. Separate role-play from evaluation

    The simulated teen and the evaluator are separate model roles. The evaluator assesses parenting technique in real time while the role-play continues.

  2. Plan for model failures

    Role-play runs on a primary model with fallbacks for errors and context overflow, and speech-to-text falls back through an ordered list of transcription models, so one failed call does not end a practice session.

  3. Pin prompts to each session

    Prompt packs are versioned, and each session keeps the version it started with, so sessions already in progress stay compatible while new sessions move to an update and versions can be compared.

  4. Layer the guardrails

    Keyword and LLM-classification guardrails detect sensitive conversation content, with trigger responses under 200 ms. A suite of 95 regression cases covers those paths.

Evidence

  • Human-verified golden set

    Dialogue consistency reached 92% on a human-verified golden set covering 5 scenarios at 3 difficulty levels.

  • Human-verified golden set

    Sensitive-content detection reached 95% accuracy on a human-verified golden set, with trigger responses under 200 ms.

Deliverables & outcomes

  • Delivered an English–Spanish role-play and assessment application deployed on Azure.
  • Paired conversational practice with a separate real-time evaluator and golden-set checks for dialogue consistency and sensitive-content detection.
  • Maintained 95 regression cases across the safety paths.

Tradeoffs

  • Realism pulls against instructional consistency: a believable teen can drift away from the scenario's learning goal. Measuring dialogue consistency on fixed scenarios keeps that drift visible.
  • More sensitive guardrails catch more risk but interrupt more legitimate practice; the golden set shows where that balance lands.
  • Fallback models keep sessions running but can behave differently from the primary model.
  • The golden sets cover defined scenarios and difficulty levels, not every conversation a parent might bring.
